# Spotify Clone — Interface Web

Estudo de **interface de plataforma musical**, com layout escuro inspirado em serviços de streaming.

**Tecnologias:** HTML5 · CSS3 · JavaScript  
**Status:** Projeto demonstrativo de front-end, sem vínculo oficial com o Spotify.

## Interface
- Navegação lateral, cards de conteúdo e biblioteca visual.
- Campo de pesquisa e barra superior.
- Área de player com controles de interface.
- Estilização com CSS, grid, transições e componentes responsivos.

## Executar

```bash
git clone https://github.com/fgscarvalho37-a11y/spotify-clone.git
cd spotify-clone
```

Abra `index.html` no navegador. Não é necessário instalar dependências de back-end.

> Esta é uma reprodução para fins de aprendizado de front-end. Não é um cliente oficial de música e não utiliza a API oficial do Spotify.
